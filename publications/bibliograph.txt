# DigiÉire Research Lab — publications, talks and outputs
# =============================================================================
# This file is the SOURCE OF TRUTH for the Publications page. It is meant to be
# edited by hand; nothing generates it.
#
# FORMAT
#   One record per block. Blocks are separated by one or more blank lines.
#   Each line inside a block is  key: value.
#   Lines beginning with # are comments and are ignored, anywhere in the file.
#   A value may be continued onto the next line by indenting the continuation
#   by two or more spaces.
#   Keys are case-insensitive. Unknown keys are ignored rather than fatal, so a
#   new field can be added here before the renderer knows about it.
#
# KEYS
#   id       required, unique, lowercase, no spaces. Used as the anchor in the
#            page URL (#pub-<id>), so changing one breaks existing links.
#   type     required. One of:
#              journal     peer-reviewed journal article
#              preprint    submitted or posted, not yet accepted
#              conference  full paper in conference proceedings
#              workshop    workshop paper or extended abstract
#              talk        invited talk, seminar, conference presentation
#              poster      poster presentation
#              book        book or edited volume
#              chapter     chapter in an edited volume
#              dataset     published dataset
#              software    released code or model
#              report      technical or policy report
#            The renderer groups by type, so a value not in this list will be
#            grouped on its own under its own name.
#   title    required.
#   authors  required. Semicolon-separated, in publication order. Write each
#            name the way it appears on the work.
#   year     required. Four digits. The renderer sorts newest first.
#   venue    journal, conference, workshop, publisher or host. Blank for
#            something with no venue.
#   status   optional, and only when the work is not simply published:
#            "Under review", "In press", "Accepted", "Submitted", "In
#            preparation". Shown as a badge.
#   pdf      filename inside publications/pdfs/. MAY BE EMPTY — a talk, a book,
#            or a link-only entry has no PDF here, and the renderer simply omits
#            the download link. Do not write a path, only the filename.
#   url      external link (DOI landing page, publisher, repository, slides,
#            recording). May be empty.
#   doi      bare DOI, no https:// and no doi: prefix. May be empty.
#   note     one short line of context. Optional.
#   tags     semicolon-separated keywords. Optional.
#
# THE APA CITATION UNDER EACH ENTRY IS BUILT FROM THE KEYS ABOVE. Nothing has
# to be written twice, so a year fixed here is fixed in the citation too. Three
# optional keys exist only to feed it, and are used when present and skipped
# when absent — an entry without them simply produces a shorter citation:
#   volume   journal volume
#   issue    journal issue
#   pages    page range, e.g. 105-128 or e26752
# And one key overrides it entirely:
#   cite     a complete citation string, used verbatim. For a work whose
#            publisher issues an exact form of words, or a kind of output APA
#            handles in a way this code does not. Leave it out and the
#            citation is derived.
#
# EVERY OPTIONAL KEY MAY BE OMITTED ENTIRELY or left with an empty value; the
# two are equivalent. Only id, type, title, authors and year are required.
#
# ORDERING IN THIS FILE DOES NOT MATTER. The renderer sorts by year descending,
# then by the order records appear here, so adding a new work at the top or the
# bottom gives the same page.
#
# A WORKED EXAMPLE OF AN ENTRY WITH NO PDF — uncomment and edit, or copy:
#

#   pdf:
#   url: https://example.org/recording

#
